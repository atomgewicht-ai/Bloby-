# Froschvolley

Ein kleines Arcade-Volleyballspiel für den Browser – eine einzige HTML-Datei, ohne Abhängigkeiten.

## Starten

`index.html` im Browser öffnen (oder z. B. über GitHub Pages ausliefern).

## Regeln

- Der Ball darf auf der eigenen Seite nicht den Boden berühren.
- Höchstens 3 Berührungen pro Seite.
- Jeder Ballwechsel gibt einen Punkt; gewonnen hat, wer zuerst 15 Punkte mit 2 Vorsprung erreicht.

## Steuerung

| | Laufen | Springen |
|---|---|---|
| Links (grün) | `A` / `D` | `W` |
| Rechts (orange) | `←` / `→` | `↑` |

`P` pausiert, `M` schaltet den Ton. Im Einzelspiel funktionieren beide Tastensätze, auf Touch-Geräten erscheinen Bildschirmtasten.

Modi: 1 Spieler gegen den Computer (drei Schwierigkeitsstufen), 2 Spieler an einer Tastatur, Demo (Computer gegen Computer).
